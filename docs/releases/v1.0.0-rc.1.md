Release candidate of the maintained worker. This is not stable `v1.0.0`, and it is not a redeploy of the hosted Cloudflare worker.

`package.json` is `1.0.0-rc.1`. The tag does not run the production or staging deploy workflows. Those stay manual, and each one requires its own confirmation phrase.

`v1.0.0-beta.1` stays where it is. The older changelog heading `1.0.0 — 2025-03-12` was not a GitHub release.
